Задача: «$ARGUMENTS» (если пусто — возьми первую открытую по «Рекомендуемому
порядку» в `TASKS.md`).

Веди её по конвейеру из CLAUDE.md, запуская субагентов (`advisor` →
`architect` → `executor` → `documenter`), и останавливайся только там, где
нужен владелец:

1. После `[DESIGN]` покажи план коротко (что получится, что изменится для
   пользователей бота, риски) и спроси «Утверждаете?». До «Да» не кодить.
2. Остальные стадии — без вопросов. В тестовом режиме после зелёного
   `npm run check` сам коммить, пушь в `main` и выкладывай (`npm run release`).
3. После каждой стадии обновляй статус задачи и блок «Сейчас» в `TASKS.md`.
4. В конце — итог в формате из CLAUDE.md (Что сделано / Что изменится /
   Как проверить / **Что нужно от вас**). Если задача закрыта — предложи
   новую сессию для следующей.
