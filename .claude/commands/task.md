---
description: Провести задачу из TASKS.md по следующей стадии конвейера
argument-hint: <ID или название задачи>
---

Найди задачу «$ARGUMENTS» в `TASKS.md` и определи её статус:

- `[REVIEW]` → запусти субагента `advisor`; по вердикту GO переведи в `[DESIGN]`.
- `[DESIGN]` → субагент `architect` пишет план в `ARCHITECTURE_PLAN.md`; затем `[READY]` — после подтверждения плана пользователем.
- `[READY]` → субагент `executor` реализует по плану и гоняет `npm run check`; затем `[DOCS]`.
- `[DOCS]` → субагент `documenter` обновляет доки по `git diff`; затем `[DONE]`.

Выполняй только одну стадию за вызов, обнови статус в `TASKS.md` и коротко
отчитайся. Если аргумент не задан — покажи таблицу задач по статусам.
