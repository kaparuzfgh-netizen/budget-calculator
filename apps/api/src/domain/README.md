# src/domain — чистые функции домена (шаг 2 миграции)

Сюда переносятся расчёты из `apps-script/*.gs` как **чистые функции без ввода-вывода**
(никаких `fetch`, `env.DB`, дат «сейчас» — только аргументы в, результат наружу):

- аннуитет и ЧДП (`DebtEngine.gs`: платёж ↓ / срок ↓) — эталон чисел: `scripts/smoke-test.js`;
- водопад месяца и каскад дельты бонуса (`CashflowEngine.gs`);
- недельный бюджет, burn rate, дневной лимит;
- конвертации валют; позже — FX-статистика (`FXAnalytics.gs`).

Каждая функция — с тестом на числах из smoke-test.js (эталон v1).
