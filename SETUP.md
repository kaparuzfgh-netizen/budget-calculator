# 🚀 Установка за 15 минут

Нужны только: Google-аккаунт, Telegram, бесплатный ключ Gemini.

---

## Шаг 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте имя и username → получите **токен** вида `123456:ABC-DEF...`.
3. Узнайте свой числовой **chat_id** у [@userinfobot](https://t.me/userinfobot) — это whitelist, бот отвечает только вам.

## Шаг 2. Создайте Google Sheet

### Быстрый путь — автосоздание (рекомендуется)

Таблицу создавать руками не нужно:

1. Откройте [script.google.com](https://script.google.com) → **Новый проект** (standalone-скрипт).
2. Вставьте файлы из `apps-script/` (как в Шаге 3) и пропишите секреты (Шаг 4).
3. Выполните функцию **`createSpreadsheet`** — она сама создаст файл `Budget Companion`
   в Google Drive, запомнит `SHEET_ID` в Script Properties и построит все листы через `setup()`.
4. В логе появится ссылка на готовую таблицу. Дальше — сразу Шаг 6 (деплой).

### Классический путь — привязанный скрипт

1. [sheets.new](https://sheets.new) → назовите `Budget Companion`.
2. `Файл → Настройки` → часовой пояс поставьте свой (например, `(UTC+6)`).
3. **Расширения → Apps Script** — откроется привязанный редактор (SHEET_ID не понадобится).

## Шаг 3. Загрузите код

1. Очистите стандартный `Code.gs`.
2. Создайте файлы (**+ → Скрипт**) с именами и содержимым из `apps-script/`:
   `Config.gs`, `Setup_Sheets.gs`, `SheetService.gs`, `TelegramService.gs`, `Code.gs`,
   `CashflowEngine.gs`, `DebtEngine.gs`, `VisionParser.gs`, `InvestNetWorth.gs`,
   `TmaApi.gs`, `Triggers.gs`.
3. Манифест: **⚙ Настройки проекта → «Показать файл манифеста appsscript.json»** →
   замените на `apps-script/appsscript.json` из проекта.

> Продвинутый путь: [clasp](https://github.com/google/clasp) — `clasp create --type sheets`,
> скопировать файлы, `clasp push` (см. `.clasp.json.example`).

## Шаг 4. Пропишите секреты (Script Properties)

**Где добавлять:** редактор Apps Script → слева **⚙ Настройки проекта** → раздел **Свойства сценария** → *Добавить свойство сценария* (имя + значение) → Сохранить. Секреты хранятся в вашем проекте и не попадают в код.

| Свойство | Как получить |
|----------|--------------|
| `TELEGRAM_BOT_TOKEN` | см. 4.1 — токен от @BotFather |
| `TELEGRAM_CHAT_ID` | см. 4.2 — ваш числовой ID |
| `GEMINI_API_KEY` | см. 4.3 — ключ Google AI Studio |
| `WEBHOOK_SECRET` | см. 4.4 — любая случайная строка |
| `TMA_READ_TOKEN` | опционально, но рекомендуется: случайная строка — защищает чтение API из браузера; тогда открывайте Mini App как `...?token=<значение>` |

> Работа с git: скопируйте `apps-script/secrets.example.json` → `secrets.json` (он в `.gitignore`),
> заполняйте значения там и переносите в Script Properties. Pre-commit хук и gitleaks не дадут
> закоммитить токены — см. [SECURITY.md](SECURITY.md).

### 4.1 TELEGRAM_BOT_TOKEN

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → отправьте `/newbot`.
2. Введите отображаемое имя (любое), затем username — обязан заканчиваться на `bot` (например `my_finance_bot`).
3. В ответ придёт сообщение с токеном вида `123456789:AAH4x...` — скопируйте его **целиком**.
4. Токен показывается один раз. Потеряли → @BotFather → `/mybots` → ваш бот → **API Token** → Revoke/показать текущий.

### 4.2 TELEGRAM_CHAT_ID

Напишите любое сообщение боту [@userinfobot](https://t.me/userinfobot) — он мгновенно ответит строкой `Id: 123456789`. Это число (положительное, без кавычек) и есть ваш chat_id — whitelist, чтобы бот отвечал только вам.

### 4.3 GEMINI_API_KEY — пошагово

1. Откройте **[aistudio.google.com/apikey](https://aistudio.google.com/apikey)** в браузере.
2. Войдите в **личный** Google-аккаунт (рабочий Workspace может быть запрещён администратором домена; карты привязывать не нужно — ключ бесплатный).
3. При первом входе появится запрос принять условия использования (Terms of Service) → **I agree / Продолжить**. (Если вместо этого пишет «Service unavailable / not available in your country» — один раз создайте ключ через VPN: ключ потом работает и без него.)
4. Нажмите **Create API key** (или **+ Create API key** вверху таблицы). Если спросит про проект — оставьте вариант по умолчанию (создастся автоматически, например `generative-language-...`).
5. В таблице появится ключ, начинающийся с `AIzaSy...` (~39 символов). Нажмите значок **копирования** слева от ключа.
6. Вставьте его в Script Properties как `GEMINI_API_KEY`.

**Проверка ключа** (после Шагов 5–7): отправьте боту любую картинку-скриншот. Ключ неверный/не задан → бот ответит точным сообщением об этом; ключ рабочий → придёт разбор суммы.

**Лимиты бесплатного ключа:** 15 запросов/мин на Gemini 2.0 Flash — на персональные скриншоты чеков хватает с запасом.

### 4.4 WEBHOOK_SECRET

Просто случайная строка из 32+ символов (латиница и цифры). Быстрый способ сгенерировать:

- в браузере: `F12` → вкладка **Console** → вставьте `crypto.randomUUID().replace(/-/g,'')` → Enter → скопируйте результат (32 символа), или
- любой генератор паролей / «надавите по клавиатуре».

Она защищает webhook от подделки. `setupWebhook` (Шаг 6) возьмёт её из Properties автоматически — главное, не меняйте после привязки.

## Шаг 5. Инициализация листов

1. Быстрый путь: выполните **`createSpreadsheet`** — таблица и листы создадутся сами (Шаг 2).
   Классический путь: выберите функцию **`setup`** → **Выполнить** → разрешите доступ.
2. Появятся 7 листов с формулами `GOOGLEFINANCE`, сидами и графиком Net Worth.
3. Сверьте в `Debt_Engine` колонку `Epoch` (дата, на которую верны начальные балансы, по умолчанию `2026-10-01`) с вашим графиком платежей.
4. Выполните **`securityAudit`** — базовая проверка безопасности (секреты, токены, webhook) должна быть зелёной.

## Шаг 6. Деплой Web App + Webhook

1. **Развернуть → Новое развёртывание → Веб-приложение**.
2. Выполнять как: **меня**; Доступ: **все** (требование Telegram Webhook).
3. Скопируйте URL (`https://script.google.com/macros/s/.../exec`).
4. Выполните функцию **`setupWebhook`** (URL подхватится автоматически; если нет — вставьте строкой в функцию).
5. Напишите боту `/start`, затем `/plan`. Молчит → выполните `debugWebhook` в редакторе и смотрите лог (URL webhook и последняя ошибка доставки).

## Шаг 7. Mini App

1. В `mini-app/index.html` вставьте URL из Шага 6 в константу `API_URL` (в начале файла).
2. Разместите файл (подробности в `mini-app/README.md`):
   - **GitHub Pages**: репозиторий → загрузить `index.html` → Settings → Pages → `main`.
   - **Cloudflare Pages**: Direct Upload → получите `*.pages.dev`.
3. @BotFather → `/setmenubutton` → выберите бота → вставьте URL → название `Дашборд`.
4. Кнопки записи (ЧДП, сценарии) работают только внутри Telegram; в браузере — режим чтения.

## Шаг 8. Проверка Vision

Отправьте боту скриншот аналитики расходов из MBANK — он ответит суммой, категориями,
burn rate и допустимым дневным расходом до конца месяца. Лимит Gemini free tier — 15 RPM.

## Что где менять

| Хочу изменить | Где |
|---------------|-----|
| Базовый доход / лимиты / ставка вклада / доли | Лист `FX_and_Settings` (таблица Config) — бот читает оттуда |
| Обязательства (суммы, Active) | Лист `Commitments_Registry` |
| Холдинги портфеля | Лист `Portfolio` (цена подтянется сама) |
| Начальные балансы ипотек | `Config.gs` → перезапустить `setup()` (идемпотентна для пустых листов) |
| Воскресный опрос | Час в `Triggers.gs → installTriggers_` + повторный `setup()` |

## Ограничения бесплатности

- Apps Script: ~90 мин/день суммарно на триггеры — здесь ≈ 1–2 мин/день.
- UrlFetch ≤ 20 000/день — используется 5–10.
- Gemini Flash: 15 RPM — на персональные скриншоты хватает с запасом.
