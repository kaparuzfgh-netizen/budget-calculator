# Аудит 04 — Бизнес и эксплуатация (пет-проект, N≈5)

Дата: 2026-10-25 · Рамка: некоммерческий проект для узкого круга; задача аудита — не «как заработать», а какие риски и обязательства возникают, когда данными владельца начинают пользоваться другие люди, и когда проект стоит остановить.

## 1. Экономика

| Статья | Оценка | Комментарий |
|---|---|---|
| Хостинг, БД, Mini App | ~$0 | Cloudflare Workers/D1/Pages на бесплатном тарифе (лимиты проверить по актуальной документации перед стартом) |
| AI (Gemini free, Groq free) | $0 | Лимиты и условия меняются без согласия; для 5 человек запросов мало |
| Данные курсов/цен | $0 | Надо выбрать бесплатный API (замена GOOGLEFINANCE) — открытый вопрос |
| Домен (опционально) | ~$10/год | не обязателен |
| **Главная статья** | **время владельца** | поддержка друзей — неоплачиваемая и непрерывная |

Монетизации нет и не планируется. Если когда-нибудь понадобится — переход на платный план делается по триггеру «превысили лимит», а не заранее.

## 2. Риски

| Риск | Вероятность | Влияние | Смягчение |
|---|---|---|---|
| Утечка/потеря финансовых данных друзей | низкая | **высокое** (репутация, доверие, возможная юридическая ответственность по местным законам о персональных данных — проверить применимое право) | минимум данных, шифрование на хранении (платформа), изоляция по `user_id`, `/delete_me`, согласие, никаких секретов в чатах |
| Данные уходят внешнему AI | средняя | среднее | явное согласие, отключаемо, ручной ввод |
| Бесплатные тарифы изменят условия | средняя | среднее | изолировать провайдеров за интерфейсом (`FxProvider`, `VisionProvider`) |
| Рекомендации воспринимают как финсовет | средняя | среднее | дисклеймер, показывать допущения |
| Единственный разработчик (bus factor 1) | высокая | среднее | документация, ADR, CI, понятные runbook'и; не обещать SLA |
| Выгорание от поддержки | средняя | высокое для проекта | ограничить круг пользователей (5), канал обратной связи — раз в неделю |
| Telegram недоступен у части аудитории | низкая | низкое | не критично для пет-проекта |

## 3. Обязательства перед пользователями (минимальный честный пакет)

Страница «Что мы храним и зачем» (на человеческом языке), согласие при онбординге, возможность выгрузить и удалить данные, отсутствие обещаний по доступности, дисклеймер «это не финансовая рекомендация».

## 4. Критерии продолжать/остановить

Продолжаем, если через 4 недели после запуска ≥ 3 из 5 пользуются еженедельно, а владелец тратит на поддержку ≤ 1 часа в неделю. Останавливаем или сворачиваем до личного инструмента, если активны < 2 из 5, либо поддержка стабильно > 3 часов в неделю, либо случился инцидент с данными, который нельзя закрыть быстро.

## 5. Что не делать

Не принимать платежи, не хранить реквизиты карт и данные подключения к банкам, не расширять круг без пересмотра безопасности и согласий, не копировать данные в сторонние хранилища без причины.
