# Гид пользователя — «Бюджет-компаньон» v2

Личный трекер финансов в Telegram: бот-команды + Mini App. Данные хранятся в
Cloudflare D1, их видите только вы (и владелец сервиса — см. условия в
онбординге). Технические детали — [ARCHITECTURE.md](ARCHITECTURE.md).

## Доступ

- **Владелец** регистрируется автоматически по первому сообщению боту
  (`OWNER_TELEGRAM_ID` настраивается при установке).
- **Участники** — по одноразовой ссылке-приглашению: владелец выполняет
  `/invite`, ссылка действует 48 часов; переход по ней открывает `/start <код>`.
- **Незнакомцам** бот не отвечает вообще — это by design, а не поломка.

## Онбординг (`/start`)

Линейная настройка в 6 шагов; на каждом — кнопка `✖ Отмена` (`/cancel`
делает то же):

1. **Согласие** на хранение данных (профиль, платежи, траты — в D1) → `✅ Согласен`.
2. **Валюта дохода** — кнопки USD / EUR / RUB / KGS или «Другая…» (код текстом,
   проверяется по курсам).
3. **Типичный доход** — число (`6200`, можно `6200 eur`) или «Пропустить»,
   если доход плавающий — тогда факт вносится через `/income`.
4. **Лимит «на жизнь»** в месяц — число (`60000`, можно с валютой `60000 rub`).
   Недельный бюджет вычисляется сам: лимит ×12/52.
5. **Часовой пояс** — кнопки (Бишкек, Москва, Алматы, Тбилиси, UTC) или IANA-имя
   текстом (`Europe/Berlin`). От него зависят даты записей и время напоминаний.
6. **Обязательные платежи** — по одному в строке:
   `Аренда 700 usd 1` (название сумма [валюта] [день месяца]), до 30 штук;
   `Готово` или `Пропустить`.

Финал — сводка профиля и главное меню (`/menu`).

## Команды

| Команда | Действие |
|---------|----------|
| `/start` | Приветствие; не онбоарден — запуск настройки, онбоарден — главное меню |
| `/menu` | Главное меню (то же, что кнопка `🏠 Меню`) |
| `/plan [сумма] [валюта]` | План месяца: доход → платежи → лимит жизни → профицит. Аргумент (`/plan 5000 eur`) — доход «вручную» на этот расчёт |
| `/week` | Неделя и месяц расходов: потрачено/бюджет, burn rate, дневной остаток |
| `/spent [сумма] [валюта] [заметка]` | Записать трату: `/spent 320 kgs кофе`. Без аргументов — вопрос «Сколько потратили?» |
| `/income [сумма] [валюта] [заметка]` | Факт дохода за текущий месяц: `/income 5200 eur зарплата`. Без аргументов — экран «Доход» |
| `/expenses` | Список трат недели |
| `/credits` (или `/debts`) | Кредиты и ипотеки |
| `/loans` | Долги людям («я должен» / «мне должны») |
| `/fx` | Курсы: анализ «когда менять» и журнал ваших обменов |
| `/profile` | Профиль: разделы и правки |
| `/export` | Файл `budget-export-<дата>.json` со всеми данными (не чаще раза в минуту) |
| `/delete_me` | Удалить все свои данные (с подтверждением) |
| `/cancel` | Отмена ввода/шага — возврат на экран-источник |
| `/help` | Список команд |
| `/id` | Мой Telegram ID |
| `/invite` | Одноразовое приглашение (только владелец, лимит 10 активных) |

Команды дублируются inline-кнопками главного меню: 📊 План · 📅 Неделя ·
➕ Трата · 💵 Доход · 🏦 Кредиты · 🤝 Долги · 💱 Курсы · ⚙️ Профиль.

**Навигация:** у экранов есть ряд `[🏠 Меню]`, у вложенных — `[← Назад] [🏠 Меню]`,
у вопросов — `[✖ Отмена]`. После сохранения вы возвращаетесь на экран, откуда
начали. Кнопки живут 24 часа; устаревшие молча игнорируются. Голая сумма вне
вопроса («320» просто в чат) тратой не записывается — бот ответит
«Не знаю такую команду».

## План месяца и неделя

- **`/plan`** показывает: доход (с источником — «задано вручную», «факт за
  <месяц>», «типичный» или «не указан»), топ-5 обязательных платежей, лимит
  жизни и **свободный профицит в USD** + строка курсов на дату выгрузки.
- **`/week`**: неделя — потрачено из недельного бюджета (лимит жизни ×12/52) и
  остаток/перерасход; месяц — потрачено из лимита + **burn rate** (доля
  истраченного бюджета к доле прошедшего месяца; >100% — тратите быстрее
  плана); **в день до конца месяца** — сколько можно тратить ежедневно.

## Траты

- Запись: `➕ Трата` или `/spent` → вопрос → `320` или `320 kgs кофе`.
  Ответ — статус недели с кнопками `[↩ Отменить]` (удалить запись) и
  `[✏️ Изменить]` (новая сумма). Защита от опечатки: сумма больше лимита
  жизни ×5 отклоняется.
- Список: `/week` → `📋 Траты недели` или `/expenses` (до 20 записей).
- Карточка траты → `✏️ Изменить` (новая сумма, можно `700 eur бензин`) или
  `🗑 Удалить` с подтверждением.

## Категории и быстрый ввод

Трата пишется просто суммой: «500 кафе» — без команды. По первому слову
заметки бот сам ставит категорию (10 пресетов: продукты, кафе, транспорт…);
совпавшее слово вырезается из заметки. Если категория не нашлась — сообщение
предложит выбрать кнопкой; кнопка «🏷 Категория» меняет её позже. Свои
категории и архив — в приложении (Mini App).

## Отчёт (/report)

«📈 Отчёт» — сводка за неделю, месяц, квартал, полгода или год: сколько
получено и потрачено (жизнь / платежи / кредиты / долги людям), итог,
доля лимита, топ категорий и сравнение с прошлым периодом. Кнопки
«‹ Раньше / Позже ›» листают периоды прямо в сообщении.

## Доход

`💵 Доход` / `/income` — итог за месяц и записи. `➕ Добавить доход` →
`5200 eur зарплата`. `📋 Записи месяца` → `🗑` удалить запись с подтверждением.
«Типичный доход» (база для плана, когда факта нет) правится в
`⚙️ Профиль → 💵 Доход`.

## Регулярные платежи

`⚙️ Профиль → 🧾 Платежи` — список (до 30, ⏸ = выключен из расчётов).

Карточка платежа: сумма, день месяца, статус, строка «Этот месяц: ✅ оплачен /
не оплачен» и последние оплаты (🤖 — записана автопроводкой). Действия:
`✅ Оплачено` (отметка текущего месяца — появляется, пока платёж не оплачен),
`✏️ Сумма`, `📅 День`, `⏸ Выключить` / `▶️ Включить`, `🗑 Удалить` (с
подтверждением), `➕ Добавить` новый (`Интернет 600 kgs 5`).

Журнал оплат платежа — в его карточке: строка оплаты → `✏️ Изменить`
(сумма, можно с датой `50000 05.10`) или `🗑 Удалить`.

## Кредиты (`/credits`)

Список с остатками и итогом ≈ в USD. `➕ Добавить кредит` — мастер:
название → остаток и валюта → ставка % годовых → платёж за период →
периодичность (ежемесячно / раз в 2 недели) → день месяца (для monthly) или
дата ближайшего платежа (для biweekly, можно «Сегодня»). Лимит — 20 кредитов.

Карточка кредита: остаток, платёж и период, ставка, число платежей, прогноз
«осталось ≈ N мес → погашение ~ГГГГ-ММ» и проценты до конца.

- `✅ Платёж` — сумма с датой (`21500 25.10`) или кнопка «По графику».
- `💸 ЧДП` — досрочное погашение: сумма → превью → выбор режима
  `📉 Платёж↓` (срок сохраняется) или `⏳ Срок↓` (платёж сохраняется).
- `🏦 Сверка` — вписать фактический остаток из выписки банка: движок
  подгонит состояние под реальность (событие `reconcile`).
- `✏️ Правки` — ставка, платёж, день платежа.
- `📜 История` — журнал событий (последние 10): платежи, ЧДП с режимом,
  сверки. Событие → `✏️ Изменить` сумму/дату, `🗑 Удалить`; у ЧДП —
  `🔀 Режим` (смена платёж↓ ↔ срок↓).
- `❌ Удалить` — кредит и его журнал (с подтверждением).

Остаток и прогноз вычисляются replay по журналу событий — правки и удаления
событий пересчитывают карточку автоматически.

## Долги людям (`/loans`)

Личные займы: `я должен` (owe) / `мне должны` (owed). `➕ Добавить` — мастер:
направление → имя → сумма и валюта → срок (можно «Без срока») → заметка
(можно «Пропустить»). Лимит — 100 открытых займов; закрытые лежат в
`✅ Закрытые` (архив).

Карточка займа: `💸 Возврат` (сумма, кнопка «💯 Вся сумма»), `📅 Срок`
(новая дата или «Без срока»), `✅ Закрыть` (остаток прощается — с
подтверждением), `🗑 Удалить` (с журналом, с подтверждением),
`📜 Журнал возвратов` — события с правкой/удалением.

## Напоминания и автопроводка

Включаются и выключаются в `⚙️ Профиль → 🔔 Напоминания` (по умолчанию
включены):

- **Еженедельный итог** — воскресенье 20:00–23:59 по вашему часовому поясу:
  «📅 Итоги недели» (та же сводка, что `/week`).
- **Платежи** — ежедневно 10:00–21:59 по вашему часовому поясу:
  - «⏰ Через 2 дня платежи» — обязательные платежи и monthly-кредиты,
    дедлайн которых через 2 дня (уже оплаченные в этом месяце не напоминают);
  - «⏰ Сроки по займам» — займы со сроком «сегодня» и «через 3 дня»;
  - **автопроводка**: monthly-кредиты и платежи с датой, чей срок в этом
    месяце уже наступил, проводятся сами — сообщением «✅ Записал автоплатежи»
    со ссылками в журналы. Дата события — день срока. Удалённая вами
    автозапись в этом месяце не воскреснет, со следующего — снова проводится.
- **Алерты по курсам** — в том же дневном окне 10:00–21:59: если курс вашей
  пары «доход → валюта жизни» (или валюты кредитов) в верхних 15% за полгода —
  «💱 Выгодное окно конвертации», в нижних 15% — предупреждение. Не чаще
  раза в неделю на пару.

Если заблокировать бота, переключатели снимутся сами — после разблокировки
включите их заново в Профиле.

## Скриншоты банка (по желанию)

Бот может разбирать скриншоты из банковского приложения нейросетью. Опция
**выключена по умолчанию**: включить — `⚙️ Профиль → 🔔 Напоминания →
✅ Вкл скриншоты`. Картинка уходит ИИ-провайдеру только при включённой опции;
выключите — и фото снова будет обрабатываться как обычная подсказка.

- Пришлите фото или файл-картинку (≤10 МБ, до 20 скриншотов в день). Подпись
  к фото не читается — разбирается сама картинка.
- **Аналитика расходов** за неделю/период → запишется одна трата этой недели
  (заметка `vision/…`), ответ — сумма, категории и статус недели. Аналитика
  за **весь месяц** не записывается — только показывается.
- **Экран кредита с остатком долга** → бот спросит «Какой это кредит?»
  (кнопки ваших кредитов) → «Сверить …?» → ✅ — тот же журнал, что ручная
  `🏦 Сверка`.
- Если не распознано — бот подскажет, какой экран прислать, или введите
  сумму вручную: `/spent 3200`.

## Курсы и обмены (`/fx`)

`💱 Курсы` / `/fx` — анализ «стоит ли менять сейчас» по дневным курсам за
полгода (Frankfurter) и журнал ваших фактических обменов.

- **Карточки пар**: «доход → валюта жизни», «доход → валюта накоплений» и
  по валюте каждого кредита. В каждой: текущий курс, стрелка и Δ за 30 дней,
  перцентиль (где курс относительно диапазона 180 дней), RSI, волатильность,
  сигнал и прогноз на 7/30 дней.
- **Сигналы** (как в v1): «боковик» — разбивайте на части; высокий курс
  (перцентиль ≥70) — «конвертируйте сейчас»; 45–69 — нейтрально; 30–44 —
  подождите; <30 — только обязательные платежи. Это статистическая модель,
  не прогноз-гарантия.
- **📋 Журнал** — ваши обмены: суммы, курс сделки и рыночный курс на день
  записи. `➕ Записать обмен` — мастер: из чего → во что (кнопки или код
  валюты текстом) → `500 → 48500` → дата (📅 Сегодня или `19.04`) → заметка.
- Карточка обмена → `✏️ Суммы` (курс пересчитается), `✏️ Дата`, `✏️ Заметка`,
  `🗑 Удалить` с подтверждением.

Обмен — это запись факта, она не трогает траты и план месяца.

## Mini App

Голубая кнопка **«💰 Бюджет»** слева от поля ввода (menu-button) открывает
Mini App внутри Telegram. Экраны:

- **Обзор** — доход месяца с источником, платежи, неделя и месяц «на жизнь»,
  burn rate, курсы. Разделы — кнопками.
- **📊 План** — итоги в USD + «доход вручную» (сумма/валюта → пересчёт,
  «Сбросить»).
- **📅 Неделя** — сводка + список трат; трата → правка суммы/валюты/заметки
  или удаление с подтверждением.
- **➕ Трата** — сумма, валюта, заметка; повторная отправка формы дубль не
  создаёт.
- **💵 Доход** — итог, добавить, удалить.
- **🏦 Кредиты** — список и добавление; карточка: платёж, ЧДП с превью
  «платёж↓/срок↓», сверка, правки, журнал событий (правка/режим/удаление).
- **🤝 Долги** — список (+закрытые) и добавление; карточка: возврат, срок,
  закрыть/удалить, журнал возвратов.
- **💱 Курсы** — карточки анализа пар, журнал обменов, добавление
  (без дублей при повторной отправке), правка и удаление обмена.
- **⚙️ Профиль** — типичный доход, лимит жизни, часовой пояс (пресеты или
  IANA); платежи — список/карточка (сумма, день, вкл/выкл, оплаты, удалить),
  добавление.

На вложенных экранах — верхняя панель «← Назад» / «🏠 На главную» и нативная
кнопка «Назад» Telegram. Вне Telegram приложение показывает «Не из Telegram»,
без онбординга — «Нет доступа».

## Mini App: отчёты, категории, оплаты

Главная «Обзор» теперь ведёт с приветствия и круглой кнопки профиля. Под
быстрыми действиями — карточка «К оплате в месяце»: все регулярные платежи и
месячные кредиты с датами; неоплаченные — кнопкой «Оплатить» (с подтверждением),
просроченные подсвечены, оплаченные — ✅.

«📈 Отчёты» — та же сводка, что /report в боте: периоды неделя…год, листание
«‹ ›», плитки получено/потрачено/итог, «куда ушли деньги», по категориям,
динамика по дням/месяцам и крупные траты (тап → карточка).

«🏷 Категории» — свои категории: добавить (эмодзи + имя), переименовать,
отправить в архив или удалить (траты остаются без категории). В форме траты —
чипы: «Авто» определяет категорию по заметке; в карточке траты категорию
можно сменить или снять («Без категории»).

## Частые вопросы

**Бот молчит.** Вам не выдан доступ: бот отвечает только владельцу и людям с
действующей ссылкой-приглашением (`/invite` у владельца, 48 часов). Если вы
уже пользовались — возможно, данные удалены (`/delete_me`); пройдите `/start`
заново по новой ссылке. Владельцу для диагностики: `npm run webhook:info`
(URL замаскирован, видны `last_error` и `pending`).

**Mini App показывает «Нет доступа».** Значит, ваш аккаунт неизвестен боту,
не прошёл онбординг или удалён — откройте бота и напишите `/start`.
Просроченный сеанс приложение обновляет само один раз; повторный отказ —
повод проверить доступ к боту.

**Платёж записался дважды.** Повторная доставка webhook и повторная отправка
формы дублей не создают (идемпотентность по ключу). Если «дубль» виден —
это две разные записи: откройте журнал и удалите лишнюю — платежи:
`Профиль → 🧾 Платежи → <платёж> → строка оплаты → 🗑`; кредит:
`📜 История → событие → 🗑 Удалить`; трата: `📋 Траты недели → карточка → 🗑`.

**Автопроводка записала лишнее.** Авто-записи помечены 🤖 в журнале оплат
карточки платежа и `auto` в журнале кредита. Удалите запись там же — до конца
месяца проводка этого объекта не повторится. Чтобы выключить автопроводку
совсем: `Профиль → 🔔 Напоминания → ⏸ Выкл платежи` (отключатся и
напоминания о платежах/сроках — единый переключатель).

**Сменить валюту или часовой пояс.** `⚙️ Профиль → 🌍 Валюта и пояс`:
валюта дохода, валюта лимита, пояс кнопками или текстом (IANA).
Внимание: при смене валюты **суммы не пересчитываются** — меняется только
обозначение. В Mini App — экран «Профиль».

**Напоминания не приходят.** Проверьте `Профиль → 🔔 Напоминания` — флаги
могли сняться, если бот был заблокирован. Окна отправки — по вашему часовому
поясу: итог недели — воскресенье 20:00+, платежи и сроки — ежедневно
10:00–21:59. Проверьте также, что в профиле верный часовой пояс.

**Скриншот не распознаётся.** Проверьте, что опция включена (`Профиль →
🔔 Напоминания → 📷 Скриншоты банка`) — при выключенной фото не уходит на
разбор. Присылайте полный экран «Аналитика/Расходы за период» или экран
кредита с видимым остатком долга; сжатие Telegram иногда мешает — попробуйте
отправить картинку файлом. Лимит — 20 скриншотов в день.

**«Не знаю такую команду» на сумму.** Голое число вне вопроса не записывает
трату (защита от случайных чисел). Используйте `➕ Трата` / `/spent`.

**Экспорт и удаление.** `Профиль → 🗄 Мои данные` (или команды `/export`,
`/delete_me`): `📤 Экспорт` — JSON со всеми данными, не чаще раза в минуту;
`🗑 Удалить всё` — профиль, платежи, траты, доход, кредиты, займы и аккаунт
стираются безвозвратно (с подтверждением). После удаления бот снова считает
вас незнакомцем — нужна новая ссылка-приглашение.
