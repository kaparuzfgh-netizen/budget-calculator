Обновлено: 2026-11-16. Приоритет: P0 — делаем следующим, P1 — после, P2 — когда появится потребность.
Источник: аудиты `docs/audits/`, ADR-0001, обратная связь владельца из живого теста.

## Принятые решения по профилю (обратная связь владельца)

| Что | Решение |
|---|---|
| Профиль нельзя править без сброса | Профиль — меню разделов. Каждый раздел правится отдельно, «пройти заново» не удаляет данные |
| Доход переменный, каждый месяц разный | Доход — **факт по месяцам** (`/income 5200 eur`), в профиле «базовый доход» (необязательный; `0` — вычисляется из платежей+бюджета+кредитов, используется, пока факт за месяц не введён) |
| Постоянные расходы (английский вырос) | Платежи редактируются: сумма, валюта, день, вкл/выкл, удалить. Сумма меняется без пересоздания |
| Ипотека/кредиты | В профиле: «есть ли кредиты» + список кредитов (баланс, ставка, платёж, периодичность) — шаг 6 |
| Инвестиции | В профиле: позиции (тикер/актив, количество, средняя цена, ручная цена) — шаг 8 |

## P1 — новый раздел «Долги людям» (по просьбе владельца) ✅

Не кредиты и не ипотека, а личные займы между людьми — реализовано
(`services/debts.ts`, `bot/debts.ts`, экран «Долги» в Mini App,
напоминания за 3 дня и в день срока, сводка «я должен / мне должны»):
- «Я занял(а) у Васи 300 $ — вернуть до 15 ноября» (я должен);
- «Мне должен Петя 20 000 ₽» (мне должны);
- поля: контрагент (имя свободным текстом), направление, сумма и валюта, срок возврата (необязательный), заметка, статус (открыт / частично возвращён / закрыт), история возвратов;
- бот напоминает: за 3 дня и в день срока «верни Васе…», для «мне должны» — «напомни Пете…»; сводка «я должен / мне должны» в `/status`;
- в `/plan` не смешивается с обязательными платежами, но можно включить «учитывать возвраты в этом месяце»;
- приватность: имена контрагентов — личные данные пользователя, входят в `/export` и `/delete_me`.

    строк трат партнёра (`services/household.ts`).
13. Дайджест «факт vs план» в конце месяца, savings rate.
14. **Игровая тема отчётов («хомяк-тамагочи»).** Альтернативный рендер экрана «Отчёты» поверх того же `Report` API — данных новых не нужно. Референс: статус-маскот («Бережливый хомяк» по % бюджета), «категории как стихии» с флейвор-подписями, «пульс трат» (линия + маркер «Ой!» на пике), «крупная дичь» (роли по ratio: Главный босс/Мелочёвка). Фазы:
    - v1: эмодзи-маскот + все правила-маппинги (титул по used_pct/streak, подписи категорий, роли трат, пульс-линия) + переключатель темы «Серьёзная/Игровая» (opt-in, дефолт серьёзная) — ~400 LOC чистого фронта;
    - v2: арт маскота — 4–6 согласованных состояний (генерация или художник; эмодзи — временный вариант);
    - v3: тамагочи-стейт из данных без новых таблиц: стрик дней в бюджете, эволюция питомца, «кормление» бережливостью.
    Условие старта: когда ядро стабильно и удобно для 2–5 реальных пользователей.

## Известные ограничения v2 (сейчас)

- Доходные и расходные категории не разбиваются по статьям: только «трата» с заметкой.
- Ограничения Telegram: inline-кнопки живут, пока сообщение есть в чате; обработка должна игнорировать устаревшие кнопки.
- Курсы только суточные (Frankfurter), без крипто и акций.
