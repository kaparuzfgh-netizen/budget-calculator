# ADR-0001 — Платформа и архитектура (v2)

Статус: **предложено, ждёт утверждения владельца** · Дата: 2026-10-25
Основание: `docs/audits/01..04`. Решения владельца: платформа — Cloudflare; vision — опционально с согласием; курсы — бесплатный API + ручной ввод; состав пользователей неизвестен (MVP минимальный).

## Контекст
Текущий код — однопользовательский бэкенд на Apps Script + Google Sheets, профиль владельца зашит в `Config.gs`. Нужны: до ~5 пользователей, изоляция данных, безопасный доступ, воспроизводимый деплой. Стек должен оставаться бесплатным.

## Решение
| Область | Решение | Почему |
|---|---|---|
| Рантайм | Cloudflare Workers, TypeScript (strict) | не засыпает, заголовок webhook проверяется, бот + API + cron в одном месте |
| БД | Cloudflare D1 (SQLite), миграции через wrangler | бесплатно, транзакции, SQL вместо листов |
| Фронтенд | Mini App на Vite + TypeScript + Tailwind (сборка), Cloudflare Pages | убирает CDN-зависимости (S8), CSP |
| Планировщик | Workers Cron Triggers | замена триггеров Apps Script |
| Секреты | `wrangler secret` | токены не в коде и не в CI-логах |
| Валидация | Zod на каждом входе | S12 |
| Тесты | Vitest (+ `@cloudflare/vitest-pool-workers` — тесты в рантайме Workers) | ловит класс ошибок S1 |
| CI/CD | GitHub Actions: lint, typecheck, test, gitleaks, `wrangler deploy`, миграции D1; токен Cloudflare минимальных прав | заменяет clasp-пайплайн |

## Модель доступа
- Telegram `initData` проверяется один раз на `POST /auth` (Web Crypto, окно `auth_date` ≤ 1 ч) → выдаётся JWT на 15 мин (HS256, секрет в `wrangler secret`).
- Дальше `Authorization: Bearer`. Токенов в URL нет. `read_token` и «демо-режим» удаляются.
- Webhook: проверка заголовка `X-Telegram-Bot-Api-Secret-Token`, fail-closed, константное сравнение.
- Допуск пользователей: таблица `users` + одноразовые приглашения (`/invite`). Незнакомые чаты игнорируются без ответа.
- Изоляция: каждая таблица данных имеет `user_id`; доступ к БД только через репозиторный слой, который принудительно добавляет `user_id`. Обязательные тесты «A не видит B». (Осознанный компромисс против Postgres RLS: изоляция на уровне кода и тестов, а не СУБД.)
- Идемпотентность денежных мутаций (`Idempotency-Key`).

## Данные (набросок, уточняется в миграции)
`users`, `profiles` (валюты, часовой пояс, язык), `commitments`, `debts`, `debt_events`, `weekly_expenses`, `monthly_cycles`, `deposits`, `holdings`, `net_worth_snapshots`, `fx_rates`, `invites`, `consents`, `audit_log`. Профиль владельца из `Config.gs` становится сид-данными его пользователя, а не кодом.

## Что переносим / что нет
- **Переносим как чистые функции (с тестами из `smoke-test.js` как эталоном чисел):** аннуитет и ЧДП (платёж ↓/срок ↓), водопад месяца, недельный бюджет и дневной лимит, конвертации, при необходимости FX-статистика.
- **MVP:** см. `02-product.md` §4.
- **Не переносим сейчас:** детектор аномалий, лист метрик, бэкап в Telegram/GitHub (заменяется `/export`), BUNDLE и clasp.
- **Курсы:** абстракция `FxProvider` + ручной ввод как запасной вариант; конкретный бесплатный API выбирается на шаге 1 плана после проверки покрытия EUR/USD/RUB/KGS и условий. Аналогично `VisionProvider` (Gemini основной, по согласию пользователя).

## Рассмотренные альтернативы
- **Supabase.** Сильная изоляция (RLS), но бесплатный проект засыпает после недели простоя; боту всё равно нужен отдельный хостинг. Отклонено; вернёмся, если изоляция на уровне кода окажется слабым местом.
- **Остаться на Apps Script.** Нельзя закрыть S2–S5 без смены платформы. Отклонено.

## План миграции (вертикальные срезы, каждый — отдельный PR)
1. **Каркас:** monorepo (`apps/api`, `apps/web`), wrangler, D1 + миграции, CI, тесты в рантайме Workers, `/health`. Выбор провайдера курсов.
2. **Ядро домена:** чистые функции расчётов + тесты, перенесённые числа из `smoke-test.js`.
3. **Доступ:** webhook, `/auth`, JWT, приглашения, согласия, репозиторный слой + тесты изоляции.
4. **Онбординг и бюджет:** профиль, `/plan`, недельный опрос (ручной ввод), напоминания (cron).
5. **Mini App:** Обзор и Долги.
6. **Долги и ЧДП** для пользователей с кредитами. 7. **Vision по согласию.** 8. **Курсы/FX-сигналы.** 9. **Импорт данных владельца из Sheets**, отключение Apps Script, удаление `apps-script/` и clasp-пайплайна.

## Последствия
Плюс: безопасная модель доступа, воспроизводимый деплой, тесты в боевом рантайме. Минус: переписывание ~8 тыс. строк; на время миграции старый бот остаётся рабочим (если запущен) до шага 9. Документы `SECURITY.md`, `SETUP.md`, `README.md` переписываются по ходу; до этого они описывают v1.
