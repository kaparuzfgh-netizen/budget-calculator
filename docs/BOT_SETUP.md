# 🤖 Настройка бота в Telegram (@BotFather)

Большинство настроек ставится **скриптом**: выполните в редакторе Apps Script
функцию **`setupBotProfile`** — она через Bot API задаст командное меню
(автокомплит «/»), описание пустого чата и «О боте». Вручную в @BotFather
остаются только иконка и кнопка Mini App.

## 1. Автоматически (`setupBotProfile` в Apps Script)

| Что настраивается | Метод Bot API | Результат |
|---|---|---|
| Командное меню | `setMyCommands` (16 команд) | при вводе «/» Telegram подсказывает команды с описаниями |
| Описание пустого чата | `setMyDescription` | текст «что умеет бот» до первого /start |
| «О боте» в профиле | `setMyShortDescription` | короткое описание в шапке профиля бота |

Повторный запуск после добавления новых команд — безопасен (перезапишет).

## 2. Вручную в @BotFather → `/mybots` → ваш бот → Bot Settings

### Edit Bot Picture (иконка)
Загрузите любое изображение 512×512 — например, скриншот иконки 💰 на тёмном
фоне или логотип из репозитория. Рекомендация: тёмный фон `#0b1220` + эмодзи
крупным кеглем — визуально совпадает с Mini App.

### Edit Name (имя)
Показывается в шапке чата. Рекомендация: `Finance Companion 💰`
(без слова «bot» — оно уже в username).

### Edit About / Edit Description
Уже ставятся скриптом (`setupBotProfile`), но вручную можно скорректировать:

**About** (профиль, до 120 симв.):
```
Личный финанс-компаньон: план → каскад → контроль. Google Sheets + Gemini, $0/мес
```

**Description** (пустой чат, до 512 симв.):
```
Личный финансовый движок: план месяца и каскад профицита, две ипотеки с ЧДП-калькулятором, траты по скриншоту MBANK (Gemini), валютные сигналы EUR→₽/сом/$, Net Worth и аномалии.

Начните с /start — или просто пришлите скриншот.
```

### Edit Commands
Уже ставится скриптом. Для ручного редактирования — актуальный список в
`Setup_Sheets.gs → BOT_COMMANDS` (16 команд: plan, income, spent, week, fx,
prepay, balance, invest, cash, status, anomalies, metrics, alias, sync, guide, help).

### Inline Mode → **Off**
Инлайн-режим (`@bot запрос` в чужих чатах) проекту не нужен и расширяет
поверхность атаки.

### Allow Groups? → **Disable**
Бот персональный (whitelist на один chat_id); в группах ему делать нечего.
Если случайно добавят — он молчит (authorizeChat_), но лучше закрыть.

### Payments / Group Settings / Others
Не используются — оставить по умолчанию (выключено).

## 3. Кнопка Mini App (меню-кнопка бота)

@BotFather → `/setmenubutton` → выбрать бота → вставить URL хостинга
`index.html` (GitHub/Cloudflare Pages) → название кнопки `Дашборд`.

Появится слева от поля ввода (☰). Токен чтения подставится автоматически
при открытии через `/app`; для браузера готовую ссылку вернёт `getAccessInfo()`.

## 4. Постоянное меню-клавиатура (reply keyboard)

Настраивается кодом, BotFather не нужен: после `/start` под полем ввода
появляются кнопки `📊 План · 💱 Курсы · 📅 Неделя · 🧮 Статус · ❓ Помощь`.
Убрать/вернуть — `/start` снова.

## Чек-лист «бот выглядит как продукт»

- [ ] `setupBotProfile` выполнен: подсказки команд «/», описание пустого чата, «О боте»
- [ ] Иконка загружена (Edit Bot Picture)
- [ ] Inline Mode: Off · Allow Groups: Disable
- [ ] `/setmenubutton` → URL Mini App, название `Дашборд`
- [ ] `/start` — меню-клавиатура на месте, кнопки работают
